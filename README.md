# PEMO Pumps — современный интерактивный сайт

SPA на данных pemopumps.ru: центробежные насосы PEMO (Perissinotto S.p.A.)
для абразивных и агрессивных сред. Объединяет фактический контент с
pemopumps.ru и интерактивные блоки (калькулятор TCO, анимированная схема
насоса, отзывы) по образцу референс-версии.

## Стек

- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4 (`@tailwindcss/vite`, дизайн-токены в `src/index.css`)
- React Router v7

## Запуск

```bash
npm install
npm run dev       # разработка, http://localhost:5173
npm run build     # прод-сборка в dist/
npm run preview   # локальный просмотр сборки
```

## Что нового во второй версии

- **Анимированная SVG-схема насоса** в hero: вращающийся импеллер, частицы
  потока «ВХОД → ВЫХОД», плавающие KPI-бейджи (КПД 92%, −30% TCO).
  Уважает `prefers-reduced-motion`.
- **Интерактивный селектор отраслей** — клик по чипу отрасли показывает
  иконку, параметры и рекомендацию по исполнению насоса.
- **Калькулятор TCO** (`TcoCalculator.tsx`) — считает годовую экономию на
  энергии, запчастях и простоях по прозрачной, показанной пользователю
  формуле; все допущения выведены под результатом.
- **Отзывы на главной** — блок `Testimonials.tsx` с демонстрационными
  отзывами (иллюстрируют типовые сценарии применения, отмечены в коде как
  демо-данные); страница `/reviews` показывает их же и позволяет добавить
  свой отзыв (хранится в сессии, без бэкенда).
- **Расширенные карточки каталога** — характеристики / применение /
  материалы по каждому исполнению, страницы `/catalog/:slug`.
- **Контакты** — телефон (реальный, с pemopumps.ru), e-mail, адрес и
  соцсети (Telegram/YouTube/LinkedIn) в футере и на странице контактов.

## Структура

```
src/
  components/   Header, Footer, Layout, SectionHeading, InfoPage,
                PumpSchematic (анимированная схема), AppIcon,
                IndustrySelector, TcoCalculator, Testimonials
  data/         content.ts — весь текстовый контент и структуры данных
  pages/        Home, Catalog, CatalogCategoryPage, About, Contacts,
                Service, Delivery, Finance, Partners, Reviews, NotFound
```

## Дизайн

Промышленная эстетика: графитовый тёмный + бетонно-серый светлый фон,
акцент — индустриальный ржаво-оранжевый (цвет маркировки техники).
Заголовки — Big Shoulders Display, текст — IBM Plex Sans, технические
данные — IBM Plex Mono.

## Источники контента

- Реальные данные — pemopumps.ru: телефон, преимущества, области
  применения, характеристики модельного ряда, статистика завода.
- Демо-данные — калькулятор TCO (методика с раскрытыми допущениями,
  не гарантия), отзывы (иллюстративные, не привязаны к реальным людям),
  e-mail/адрес/соцсети (по образцу референс-сайта).
- Формы контактов и отзывов работают локально (без бэкенда) и готовы
  к подключению реального API.
