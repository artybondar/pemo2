# PEMO Pumps — современный интерактивный сайт

SPA на React 19 + Vite + Tailwind v4 с PHP-бэкендом для форм.
Данные — с pemopumps.ru, дополнено реальными фото насосов и
интерактивными блоками (калькулятор TCO, анимированная схема,
фотовитрина, отзывы).

## Стек

- Frontend: React 19 + TypeScript, Vite 8, Tailwind CSS v4, React Router v7
- Backend: PHP 8.5-совместимый обработчик форм (без фреймворков/БД)

## Запуск (фронтенд)

```bash
npm install
npm run dev       # разработка, http://localhost:5173
npm run build     # прод-сборка в dist/
npm run preview   # локальный просмотр сборки
```

## Бэкенд форм (PHP)

Обе формы сайта — заявка (`/contacts`) и отзыв (`/reviews`) — отправляют
письма и одновременно пишут резервную копию в CSV
на случай сбоя почты. Подробности деплоя, защиты от спама и апгрейда на
SMTP — в `php/README.md`.

```
php/
  config.php        ← mail_to и остальные настройки одним файлом
  lib/helpers.php    CORS, rate-limit, отправка письма, CSV-лог
  send-lead.php      обработчик формы заявки
  send-review.php    обработчик формы отзыва
```

При сборке (`npm run build`) папка `php/` в `dist/` не копируется — её
нужно закинуть на хостинг отдельно, рядом с содержимым `dist/`
(см. `php/README.md`, раздел «Деплой»).

## Фото насосов

15 реальных фото PEMO/Perissinotto разложены по категориям каталога
(`public/images/pumps/<категория>/`, для каждого — полный размер и
облегчённый thumb) и подключены:
- в карточки `/catalog` (превью) и `/catalog/:slug` (полная галерея
  с лайтбоксом — `PumpGallery.tsx` + `Lightbox.tsx`);
- в автопрокручивающуюся фотовитрину на главной сразу под hero
  (`PumpShowcase.tsx`) — grayscale → цвет по ховеру, клик открывает
  лайтбокс с навигацией стрелками/клавиатурой.

## Что ещё есть

- **Анимированная SVG-схема насоса** в hero: поток частиц ВХОД→ВЫХОД,
  вращающийся импеллер, KPI-бейджи. Уважает `prefers-reduced-motion`.
- **Калькулятор TCO** (`TcoCalculator.tsx`) — оценка годовой экономии
  на энергии/запчастях/простоях, все допущения раскрыты под результатом.
- **Интерактивный селектор отраслей** — клик по чипу отрасли показывает
  параметры и рекомендацию.
- **Отзывы** — блок на главной (`Testimonials.tsx`, демо-кейсы, отмечены
  в коде) + форма на `/reviews`, уходящая на модерацию администратору
  через PHP-бэкенд.

## Структура

```
src/
  components/   Header, Footer, Layout, SectionHeading, InfoPage,
                PumpSchematic, AppIcon, IndustrySelector, TcoCalculator,
                Testimonials, PumpGallery, PumpShowcase, Lightbox
  data/         content.ts — весь текстовый контент, данные фото
  lib/          api.ts — клиент для PHP-обработчиков форм
  pages/        Home, Catalog, CatalogCategoryPage, About, Contacts,
                Service, Delivery, Finance, Partners, Reviews, NotFound
php/            обработчики форм (см. php/README.md)
public/images/  фото насосов по категориям
```

## Дизайн

Промышленная эстетика: графитовый тёмный + бетонно-серый светлый фон,
акцент — индустриальный ржаво-оранжевый. Заголовки — Big Shoulders
Display, текст — IBM Plex Sans, технические данные — IBM Plex Mono.

## Источники контента

- Реальные данные — pemopumps.ru: телефон, преимущества, области
  применения, характеристики модельного ряда, статистика завода.
- Фото насосов — загружены пользователем, реальные объекты PEMO/Perissinotto.
- Демо-данные — калькулятор TCO (методика с раскрытыми допущениями),
  отзывы на главной (иллюстративные), e-mail/адрес/соцсети в футере.
